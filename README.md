# MotionHub

Staff Hub (Electron) — notes, rules, stats, tournament tools.

## Run (dev)

```powershell
cd C:\Users\Halep\MotionHub\hub-app
npm start
```

## Build

```powershell
cd hub-app
npm run build
```

The built app is in `hub-app/dist/` (e.g. portable `.exe` or installer).
