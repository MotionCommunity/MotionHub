========================================
  MOTION STAFF HUB — DOWNLOAD & UPDATE
========================================

This folder always has the latest Staff Hub. One file, one link.

HOW TO GET THE LATEST VERSION
-----------------------------
1. Download "Motion-Staff-Hub-LATEST.exe" (click it, then click Download or the download icon).
2. Run the downloaded file.

UPGRADING FROM AN OLDER VERSION (no uninstall needed)
-----------------------------------------------------
• If you already have the hub installed:
  - Download Motion-Staff-Hub-LATEST.exe from this folder.
  - Move the new file to the same place as your current hub (e.g. Desktop or your folder).
  - When Windows asks "Replace file?", choose Replace. Your shortcut will still work.
• Or: run the new .exe from your Downloads folder — both versions can coexist. Use the new one.

You never need to delete or uninstall the old app. Just run the new one (or replace the old file with it).
